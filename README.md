# Proyecto 7 - Análisis de anuncios de vehículos

Proyecto desarrollado en el Bootcamp de Data Science de TripleTen.

## Descripción

Esta aplicación web permite explorar un conjunto de datos de anuncios de venta de vehículos mediante visualizaciones interactivas.

La aplicación fue desarrollada con Streamlit y utiliza Pandas para el manejo de los datos y Plotly para la creación de gráficos interactivos.

## Funcionalidades

- Filtrar los anuncios por tipo de vehículo.
- Consultar la cantidad de vehículos del conjunto de datos seleccionado.
- Consultar el precio promedio de los vehículos.
- Consultar el millaje promedio.
- Generar un histograma para analizar la distribución del millaje.
- Generar un gráfico de dispersión para analizar la relación entre el millaje y el precio.
- Cambiar entre modo claro y modo oscuro.

## Tecnologías utilizadas

- Python
- Pandas
- Plotly
- Streamlit

## Ejecución local

Para ejecutar la aplicación:

```bash
streamlit run app.py
```
